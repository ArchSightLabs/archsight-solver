# ArchSight Solver v1.8.1 产品与架构计划

> 状态：实现完成，发布候选就绪
> 规划日期：2026-08-24
> 目标版本：`v1.8.1`
> 版本主题：**可复算的二维弹性几何非线性分析**

## 1. 版本定位

v1.8.1 不增加新的结构类型，也不把 v1.8.0 的“真实 P-Delta”换一个名字重新发布。它补齐 v1.8.0 固定初始几何迭代的专业边界，使二维框架具备可版本化、可失败、可复算、可教学的弹性几何非线性分析（GNA）；配置初始缺陷时属于弹性几何非线性含缺陷分析（GNIA）。

本版的核心闭环是：

> 选择算法与荷载路径 → 逐步求解更新后几何的平衡状态 → 同时检查收敛与稳定性 → 回放关键路径和失败恢复 → 与首阶/旧算法/线性屈曲比较 → 导出同源计算证据。

专业边界保持明确：二维、Euler-Bernoulli 梁柱、材料线弹性、静力、保守荷载。材料屈服、塑性铰、纤维截面、局部屈曲、侧扭屈曲、三维效应、施工阶段和 GMNIA 不属于 v1.8.1；结果不得冒充规范承载力或安全系数。

## 2. 求解器契约

### 2.1 算法版本

- `initial_stress_v1`：保留 v1.8.0 的初始应力/几何刚度迭代，用于旧项目复算；不改变既有数值结果。
- `corotational_newton_v1`：新增二维共回转梁柱单元和全 Newton-Raphson 平衡路径；新建项目的专业模式使用该算法。
- 每次结果、计算书、可信计算包和失败材料都记录算法 ID、契约版本、关键求解参数与限制，不能只显示“P-Delta”。

### 2.2 共回转单元

单元以初始弦长和初始方向为参考，在当前节点坐标上计算弦长、刚体转角、轴向伸长和两端相对转角。基本内力采用线弹性轴向与弯曲关系；全局内力和一致切线同时包含材料项与几何项，并满足：

- 刚体平移和刚体转动不产生伪内力；
- 小位移极限退化为既有线性框架单元；
- 拉力方向表现为几何加刚，压力方向表现为几何软化；
- 内力残差由当前几何直接计算，不能用“上一轮轴力对应的切线方程残差”代替；
- 端部转动释放、节点弹簧和一般线性约束若被支持，必须进入同一平衡方程；未支持的输入必须稳定拒绝，不能静默回落到旧算法。

### 2.3 荷载路径与初始缺陷

- 默认使用自适应荷载控制：成功步可受控放大，失败步按确定性规则 cutback，低于最小步长后显式失败。
- 支持固定预荷载与可缩放变量荷载的独立路径；工况和组合仍分别求解，禁止把非线性响应线性叠加。
- 初始缺陷是模型几何的版本化偏置，不是结果图的显示偏移。缺陷可来自显式节点偏移或选定线性屈曲模态与幅值；来源、归一化和幅值必须进入证据链。
- 本版不以弧长法追踪极限点后的平衡路径。达到切线奇异、稳定指标越界或最小步长仍不收敛时，返回最后收敛点和完整尝试记录，而不是伪造最终成功结果。

### 2.4 收敛、稳定性与恢复

每次迭代至少同时检查：

1. 约束允许空间内的相对不平衡力范数；
2. 绝对最大不平衡力；
3. 相对位移增量范数；
4. 绝对位移增量；
5. 能量增量或等价功判据。

Newton 步可启用确定性线搜索。收敛只证明当前荷载因子处满足平衡；稳定性另以约束空间切线刚度的最小特征指标、线性屈曲参考及趋势诊断表达。`equilibriumStatus` 与 `stabilityStatus` 必须分开，禁止把“迭代收敛”显示为“结构安全”。

失败结果至少保留：最后收敛荷载因子、最后收敛位移摘要、失败步、尝试步长、迭代残差、线搜索结果、cutback 次数、稳定指标、稳定错误码和建议动作。

## 3. 证据与教学能力

三类结构继续共用 `CalculationTrace@1`。v1.8.1 只为声明相应能力的二维框架结果增加可选事实层：

- `NonlinearPathTrace@1`：荷载步、迭代、残差、位移增量、能量增量、线搜索、cutback、稳定指标和有界位移关键帧；
- `MethodComparison@1`：首阶、`initial_stress_v1`、`corotational_newton_v1` 和线性屈曲参考的可比指标、不可比原因及来源哈希；
- `ExplanationPack`：按算法 ID 绑定的静态分层解释，不进入数值结果，也不由生成式 AI 临时解释。

前端采用能力驱动渲染，梁系和桁架不实现伪造的非线性迭代：

- `supportsMethodComparison`
- `supportsIterationPlayback`
- `supportsNonlinearGeometry`
- `supportsBucklingModes`

教学能力限定为“读懂并复核当前求解”：方法对比、过程播放、入门/工程/算法三层解释、公开算例和可下载证据。它不把所有结构类型改造成课程系统，也不要求教师讲授塑性、弧长或后屈曲。

所有路径曲线必须检测并标注工程关键点：最后收敛点、cutback 点、残差峰值、稳定指标最小点及终止点。默认图面可避碰隐藏标签，但完整点集必须在表格、计算书和可信包中同源保留。

## 4. 公开验证矩阵

实现前先锁定下列可复算案例及容差；目标值来自解析解、独立数值积分或公开经典基准，不能由待测求解器自证：

| 类别 | 必须证明的性质 |
|---|---|
| 单元客观性 | 任意刚体平移/转动内力近零；切线有限差分复核 |
| 线性极限 | 低荷载悬臂和门架与线性解一致 |
| 拉压方向 | 同等轴力下压力放大、拉力减小侧移 |
| 受压悬臂 | 临界前位移放大与解析/高精度参考一致 |
| Williams toggle frame | 大转动路径、Newton/cutback 与公开参考一致 |
| Lee frame | 极限点前路径与公开参考一致，荷载控制不能越过极限点时显式停止 |
| 初始缺陷柱 | 缺陷幅值趋零与完美模型边界一致，幅值增大时响应方向确定 |
| 端释放/弹簧/斜支座 | 能力声明与约束、反力和零端弯矩一致 |
| 荷载类型 | 节点、分布、构件集中、温度及支座位移逐类验证或稳定拒绝 |
| 确定性 | 相同请求的路径、关键点、失败码和摘要逐字段稳定 |

## 5. 架构边界

```mermaid
flowchart LR
    A[Frame request] --> B{algorithm}
    B --> C[initial_stress_v1]
    B --> D[corotational_newton_v1]
    D --> E[Element state + consistent tangent]
    E --> F[Adaptive path controller]
    F --> G[Equilibrium result]
    F --> H[Last-converged failure evidence]
    G --> I[NonlinearPathTrace@1]
    H --> I
    C --> J[MethodComparison@1]
    G --> J
    K[Linear buckling] --> J
    I --> L[Workbench / DOCX / XLSX / trusted package]
    J --> L
```

求解内核只产生确定性事实；应用层组装稳定结果；Presenter 生成 canonical response；前端、DOCX、XLSX 与可信计算包只消费契约。任何载体不得重新计算收敛、稳定性或方法优劣。

## 6. 发布否决条件

以下任一项成立，v1.8.1 不得发布：

- 新算法仍使用初始方向/初始长度计算全部迭代内力；
- 切线与内力不一致，或刚体转动产生伪内力；
- 仅用位移增量宣布收敛，或把收敛等同于稳定/安全；
- cutback 用尽后丢失最后收敛点，失败材料只有一段错误文字；
- 不支持的荷载、释放或约束静默回退到 `initial_stress_v1`；
- 初始缺陷只改变显示图，不进入模型几何和哈希；
- 旧项目没有明确算法版本，升级后无法复算 v1.8.0 结果；
- 路径播放、方法比较或计算书从前端临时推导数值；
- 公开基准、后端全量、前端检查/构建、浏览器验收或正式制品门禁未通过。
