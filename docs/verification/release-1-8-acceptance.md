# v1.8.0 发布验收

> 状态：实施中。任一产品、隐私、数值、浏览器、制品或部署门禁未完成时保持 HOLD。

## 发布定位

v1.8.0 的主题是“可验证的结构力学学习与复核工作台”。本版不新增求解对象，而是把既有模型、图形、计算结果、公开 benchmark、计算书和可信计算包组织成三条可完成、可解释、可导出的专业路径。

## 产品门禁

- [ ] 公开案例入口置顶梁、平面桁架、平面框架三条五分钟路径。
- [ ] 每条路径完成“模型关注点 -> 三项预判 -> 计算 -> 图形核对 -> A 级解析证据 -> 导出”。
- [ ] 三类结构术语和主指标正确，桁架路径不引入弯矩或剪力主指标。
- [ ] 旧项目、非学习公开案例、普通求解和普通导出无回归。

## 证据与隐私门禁

- [ ] DOCX/XLSX 记录路径、预判选择、标准结论、匹配状态、caseId、验证等级和来源。
- [ ] 可信计算包携带枚举化学习复核，不包含模型之外的自由文本或身份字段。
- [ ] 匿名里程碑事件只携带分析类型，不记录 caseId、题目、选项、模型、参数、结果、文件、项目或身份。
- [ ] 第三方求解器对标明确版本、单元、单位、假定与证据等级，不暗示授权或认证。

## 工程门禁

- [ ] 后端全量测试与独立刚度法基准通过。
- [ ] 前端 lint / TypeScript、全量单元测试、生产构建和依赖审计通过。
- [ ] Chromium / Firefox / WebKit 的三条路径和导出矩阵通过。
- [ ] Python 分发包、Host Client、Docker 候选镜像和发布制品通过隔离验证。
- [ ] 版本、CHANGELOG、README、release notes、OpenAPI 和在线入口无漂移。

## 正式发布门禁

- [ ] 中文 Lore Commit 完整、工作树干净。
